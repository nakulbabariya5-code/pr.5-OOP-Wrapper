# Employee Management System

A simple Python project built using Object-Oriented Programming (OOP). It allows users to create and display Person, Employee, and Manager details through a menu-driven program.

### Concepts Used
- Classes and Objects
- Inheritance
- Multilevel Inheritance
- Encapsulation
- Getters and Setters
- Method Overriding
- `super()` function
- While Loop and Conditional Statements
